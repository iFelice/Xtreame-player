# Backup — ottobre 2026

Questa cartella conserva implementazioni precedenti che non costituiscono più la base delle applicazioni definitive.

## Contenuto

- `prototipi-capacitor/android/`: prototipo Android/Android TV basato sulla WebView React.
- `prototipi-capacitor/ios/`: prototipo iOS basato sulla stessa interfaccia web desktop.
- `prototipi-capacitor/capacitor.config.ts`: configurazione usata dai due prototipi.

I file sono mantenuti esclusivamente come riferimento storico e funzionale. Non devono essere aperti come progetti definitivi né usati per generare le future release native.

Non eliminare questa cartella finché le nuove app native non avranno raggiunto la parità funzionale.
