# Ambiente di sviluppo e pulizia

Regole del progetto:

- non presumere la presenza di strumenti sul Mac;
- usare software open source o gratuito;
- installare solo ciò che è necessario alla fase corrente;
- preferire wrapper e runtime inclusi nel progetto/IDE;
- non installare pacchetti globali quando evitabile;
- documentare installazione, versione, spazio e disinstallazione;
- non caricare credenziali, certificati, chiavi private o keystore su GitHub.

Prima di ciascuna piattaforma verrà aggiunta una guida passo passo. Al termine del progetto verrà preparata una procedura controllata per rimuovere Xcode, simulatori, SDK, cache e altri strumenti non più necessari.
