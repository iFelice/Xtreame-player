# Materiale di riferimento

La cartella `Progetto-APK/` nella radice contiene l'estrazione apktool/JADX dell'APK fornito come riferimento per studiare proporzioni, navigazione D-pad e organizzazione delle schermate Android TV.

Non è codice sorgente del prodotto e non deve essere usato direttamente nelle applicazioni FelixVisionPlayer. Non viene spostata in questa fase perché contiene oltre 27.000 file e circa 642 MB: rinominarla produrrebbe un cambiamento Git inutilmente enorme. Verrà mantenuta separata dal codice applicativo.
